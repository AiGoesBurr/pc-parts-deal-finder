Reliable sources

This app aggregates from the following sources.

  • PassMark CPU Benchmarks (cpubenchmark.net) — CPU Mark scores, prices, CPU Value. Intel, AMD, Apple/ARM lists.
  • PassMark Video Card Benchmarks (videocardbenchmark.net) — G3D Mark scores, prices, GPU value across tier pages.
  • PCPartPicker (via community mirror) — Memory, storage, PSU, motherboard, case, cooler, monitor, keyboard, mouse, headphone prices & specs.
  • TechPowerUp CPU Specs (techpowerup.com) — CPU core/thread counts and sockets.
  • Slickdeals (slickdeals.net) — Live PC hardware deals.
  • ECB daily rates (ecb.europa.eu) — Currency conversion for non-USD regions.
