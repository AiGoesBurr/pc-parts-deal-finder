Install the app

This is a Progressive Web App. You can install it on your device for quick access and offline use.

Android (Chrome)

  1. Open this site in Chrome.
  2. Tap the menu (⋮) → Install app (or "Add to Home screen").
  3. Confirm. An icon will appear on your home screen.

iPhone / iPad (Safari)

  1. Open this site in Safari.
  2. Tap the Share button (square with arrow).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. The icon appears on your home screen.

Desktop (Chrome / Edge)

  1. Open this site in Chrome or Edge.
  2. Click the install icon in the address bar (or menu → "Install PC Parts Deal Finder").
  3. Confirm. The app opens in its own window.

Manual install button

If no install prompt appears, use the browser menu steps above.
